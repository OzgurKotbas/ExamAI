# Answer tablosundan düşük puanlı konular sorgulanır
weak_ans_res = await db.execute(
    select(Question.topic)

## 3. PDF/Görsel Ön İşleme — OpenCV Entegrasyonu 🖼️

### Değişen Dosyalar
- `backendWindsurf2/services/ocr_service.py`

### Yapılan Değişiklikler

`_enhance_for_ocr()` fonksiyonu **OpenCV tabanlı** güçlü ön işleme pipeline'ı ile güncellendi:

1. **Grayscale dönüşümü** — Renk gürültüsü ortadan kalkar
2. **CLAHE** (Contrast Limited Adaptive Histogram Equalization) — Bölgesel kontrast iyileştirmesi
3. **Gaussian Blur** — Gürültü azaltma
4. **Adaptive Thresholding** — Metin/arka plan ayrıştırma için binarizasyon

**Fallback stratejisi:** OpenCV kurulu değilse otomatik olarak PIL tabanlı yönteme geçer (eskiden kullanılan `ImageEnhance`).

`requirements.txt`'de `opencv-python>=4.8.0` zaten mevcut.

## 4. API Önbellek Optimizasyonu 🚀

### Değişen Dosyalar
- `backendWindsurf2/services/cache_service.py`
- `backendWindsurf2/routers/quiz.py`

### Yapılan Değişiklikler

**Hata tespiti:** Önceki `_build_cache_key` fonksiyonu `language` parametresini dahil etmiyordu. Bu, Türkçe ve İngilizce aynı parametre ile oluşturulan sınavların aynı cache key'e düşmesine neden oluyordu.

**Düzeltme:**
```python
def _build_cache_key(user_id, note_id, total_questions, mc_ratio, difficulty, language="tr"):
    raw = f"{user_id}:{note_id}:{total_questions}:{mc_ratio:.2f}:{difficulty}:{language}"
    digest = hashlib.sha256(raw.encode()).hexdigest()
    return f"quiz:cache:{digest}"
```

- `get_cached_quiz()`, `set_cached_quiz()` fonksiyonlarına `language` parametresi eklendi.
- `create_quiz` endpoint'inde cache kontrolü ve kaydetme işlemleri `language` ile güncellendi.
